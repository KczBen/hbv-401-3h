\section{The user stories}

\begin{enumerate}
    \item As a user, I want to see photos of the hotel so that I can get an idea of what it looks like.
    \item As a costumer, I want to be able to see the prices of the rooms so that I can choose the best option for me.
    \item As a user, I want to be able to see the location of the hotel on a map so that I get a feel for where it is.
    \item As a user, I want to be able to see reviews of the hotel so that I can get an idea of what other people think of it.
    \item As a user, I want to be able to filter the hotel listings so that I can quickly narrow down the options.
    \item As a user, I want to be able to easily find contact information for the hotel so I can get in touch with them.
    \item As a user, I want to be able to compare hotels so I can find the best one for my needs.
    \item As a user, I want to be able to make reservations at any hotel on the site. % how to justify these? duh? you're here to book a hotel? %
    \item As a user, I want to be able to cancel my reservations at the hotels. % same as above %
    % should probably get some dev perspectives from the T team, if they have any specific requests %
\end{enumerate}
